## 轻羽浏览器 1.4.1

修复关闭窗口后会话丢失、关闭首个窗口导致其他窗口退出，以及快速切换标签时初始化和挂起任务冲突的问题。后台标签按驻留预算回收，普通切换不再逐个强制 GC，内存统计只计入轻羽使用的 WebView2 进程。

其他修复：

- 无痕窗口不保存普通历史和下载记录，关闭时等待私有内核退出后清理临时数据。
- 图片开关拦截实际网络请求；首页搜索、快捷键和下载文件定位恢复正常。
- 修复首次登录密码保存，凭据按协议、主机和端口隔离；内部页面消息增加来源校验。
- 修复主题字体释放和倍率刷新异常，清理未使用的 WPF 引用及编译警告。
- 安装包附带经微软签名验证的 WebView2 引导程序，避免缺失内核时 HTTPS 下载失败；卸载不再结束其他应用的 WebView2 进程。

### 安装

下载 `FeatherBrowser-1.4.1-setup.exe`，适用于 Windows 10 / 11 x64，约 49.3 MiB。已包含 .NET 8 运行时；WebView2 缺失时会询问是否联网安装。

`FeatherBrowser-1.4.1-SHA256.txt` 用于校验下载文件。普通升级保留个人数据。

### 验证

- Release 自包含发布和 NSIS 3.13 编译成功，零警告、零错误。
- 自包含回归程序与安装负载的应用程序集 SHA-256 一致，18 项真实 WebView2 回归检查全部通过。
- 测试使用本地回环服务及独立临时数据目录。未在当前工作电脑执行系统级安装、卸载，也未重新测量长期内存曲线。

详细修复及测试报告见仓库的 `docs/fixes-2026-10-01.md` 和 `docs/regression-report.txt`。
