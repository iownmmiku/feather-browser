# 1.5.1 界面与操作修复

用户反馈界面仍有遮挡、操作衔接不顺。检查发现此前的回归没有打开设置窗口，也没有模拟网页内的键盘输入和标签拖动。这次补充这些路径，并验证 Chromium 原生窗口的位置。

## 修复

- `ThemedTextBox` 在构造期间设置 Padding 就会触发布局，此时 Inner 尚未赋值，导致打开设置窗口发生空引用异常。增加初始化保护，移除与手动居中冲突的 Dock。
- 内存面板的四条统计原来放进同一布局单元。改成独立行，内容滚动与底部按钮分开；设置窗口同样使用滚动内容和固定操作区，字段随宽度调整。两个窗口均限制在屏幕工作区内。
- 标签鼠标抬起时，原逻辑先清除拖动标记再检查标记，因此排序动作永远不执行。现在先保存提交状态，并在丢失鼠标捕获时取消拖动。
- 标签栏为新建按钮保留区域；布局阶段计算全部点击区域，绘制阶段只读取。切换、新建、关闭或缩小窗口时，将当前标签滚入可视范围。
- Chromium 原生子窗口的按键不会可靠进入 WinForms KeyPreview。新增 CEF KeyboardHandler，与 WinForms ProcessCmdKey 共享快捷键表；在界面线程执行命令，仅对当前标签生效。普通编辑快捷键仍交给网页，Escape 先允许网页处理。
- 新建标签聚焦地址栏；页面导航不会抢走输入焦点。切换标签清除旧的未提交地址，Esc 恢复当前网址。提交地址和关闭查找时聚焦真正的网页控件。
- 网页缩放由各标签保存；主键盘与数字键盘的放大、缩小、复位语义一致。整体界面倍率通过菜单或设置调整，并更新所有已打开的主窗口。
- 全屏隐藏工具栏、标签栏、查找条、侧栏、进度条与状态栏，退出后恢复此前窗口大小、最大化状态和面板状态。网页全屏回调接入相同布局；地址栏等浏览器命令退出全屏，避免聚焦隐藏控件。关闭全屏窗口保存进入前的窗口状态。
- 通过原生历史返回首页时恢复内部首页地址；原生查找回调显示匹配数量；刷新按钮在加载期间变为停止，停止后及时清除加载状态。

## 验证

Release 编译无警告、无错误，39 项回归通过，其中新增 10 项交互与布局检查。测试使用隔离的临时用户数据和本地 HTTP 服务，不访问真实个人密码、会话或下载目录。

新增检查覆盖：拖动提交、24 个标签溢出及缩放前后的点击区域、内存统计独立布局、CEF 原生按键只执行一次、全屏恢复、地址编辑与焦点、网站用户点击发起全屏、历史回首页与查找计数、150% 界面倍率下的 640×480 工作区，以及四档倍率下 Chromium 原生窗口和网页容器的实际矩形一致。

完整测试须在正常 Windows 用户上下文中运行，密码相关测试使用 DPAPI；受限沙箱中系统密钥不可用。内存/设置对话框另生成截图供检查。报告见 `regression-1.5.1.txt`。

本轮没有执行管理员安装与卸载，也没有穷尽第三方网站、DRM 视频、各 Windows 版本或实际跨显示器 DPI 切换。CEF 内核保持 152.0.60。
