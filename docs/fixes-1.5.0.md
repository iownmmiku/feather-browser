# 1.5.0 修复与验证（2026-10-01）

本轮针对网页顶部被遮挡、右侧菜单无法使用，以及任务管理器同时出现 WebView2 和浏览器的反馈。

## 页面与侧边栏

根窗体使用独立的网页容器。顶部工具栏、标签栏、加载指示、查找条和底部状态栏按照 WinForms 逆向 Z 顺序 Dock；网页填充余下空间。标签侧边栏在该容器右侧停靠，展开时缩小网页宽度。不再通过改变 Z 顺序或隐藏网页实现侧边栏。

侧边栏在滚动、数据更新、可见性与尺寸变化后重算命中区域。标题与底部工具区排除在标签命中区之外；键盘选择保持活动标签可见。回归测试覆盖 100%、115%、130%、150% 界面倍率、窗口大小变化、查找条和反复展开侧边栏。

## 菜单

PopupMenu 使用拥有者窗体派发动作，关闭弹层后仍能打开历史、下载等页面。修复非模态标签菜单被 using 提前 Dispose 的问题。变高菜单项计算实际总高，按屏幕工作区限制大小，列表自动滚动。方向键、Home、End 跳过分隔项，Enter 执行动作，Esc 关闭菜单。测试覆盖小屏幕和负坐标显示器。

## CEF 迁移

使用 CefSharp.WinForms.NETCore 152.0.60 和 CEF 152.0.6。Program.Main 在访问数据或创建窗口之前执行 SelfHost.Main，渲染、GPU、网络子进程使用自身 FeatherBrowser.exe。仍是 Chromium 多进程，Windows 决定任务管理器分组方式。

普通窗口共享请求上下文；私密上下文没有磁盘 CachePath。CEF 数据使用 Chromium 子目录，旧 WebView2 数据保留。轻羽设置和 JSON 数据格式保留，网站 Cookie 不迁移。

浏览器事件先复制参数再投递到 WinForms。CEF 消息桥在原生回调期间复制 frame 来源，仅接受主 frame 的字符串消息，并校验当前视图与当前来源。避免基类线程池事件读取已释放的原生 frame 包装，或将外部页面、子 frame 消息作为管理页命令执行。

视图关闭处理器通过接口保留到 CEF 关闭回调结束，避免基类 Dispose 清空 handler 后将 WM_CLOSE 发给主窗体。初始化中的视图延后销毁 HWND；快速切换合并尚未启动的创建请求。窗口退出等待启动任务和待销毁控件，不让父 HWND 提前消失。

再次启动同一数据目录时，使用命名互斥锁与当前用户专用管道转交打开窗口请求，避免第二个宿主争用 CEF 的缓存目录。

导航、前进后退、网页缩放、主题、图片与广告拦截、JavaScript 策略、缓存设置、Cookie 策略、密码提交助手、下载与内部页面全部重新接入。页内查找改用 CEF 原生查找。内存统计使用父进程树，只计当前宿主的同名子进程。

## 安装包

内置 .NET 8、Chromium 与 CEF 资源及许可证。删除 WebView2 引导安装步骤，附带经微软 Authenticode 验证的 VC++ x64 运行库，缺失时离线安装。卸载按发布文件清单删除文件和空目录，默认保留用户数据。
