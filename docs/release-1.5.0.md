轻羽浏览器 1.5.0 修复网页顶部遮挡、右侧菜单点击无响应和标签侧边栏滚动命中问题，并将内核从 WebView2 更换为 CEF Chromium。

- 主进程和 Chromium 子进程都使用 FeatherBrowser.exe，不再依赖或启动 WebView2；仍保留多进程架构，任务管理器具体分组由 Windows 决定。
- 网页与侧边栏并排显示；长菜单可滚动，鼠标与键盘动作正确执行。
- 修复快速切换、初始化中关闭标签和多窗口退出；再次启动在已有宿主打开窗口。
- 完成导航、下载、无痕 Cookie 隔离、拦截、密码助手和原生页内查找迁移。
- 29 项真实 Chromium 回归检查通过，Release 编译 0 警告、0 错误。

安装包面向 Windows 10 / 11 x64，包含 .NET、Chromium 与 VC++ 依赖。体积比旧版增加。请先关闭旧浏览器再升级。

已有书签、设置、历史与轻羽保存的密码会保留。网站 Cookie 与登录状态不迁移，需要重新登录；旧 WebView2 缓存保留。卸载默认保留个人数据。
