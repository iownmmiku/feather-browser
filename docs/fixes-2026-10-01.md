# 2026-10-01 全面检查与修复

本轮重点是低内存策略、窗口生命周期和实际失效的用户功能。

## 已修复

- **会话丢失**：关闭窗口时先保存标签和窗口尺寸，再销毁视图。退出后重复保存不会清空会话；无痕窗口不覆盖普通会话。
- **多窗口连带关闭**：使用独立的应用消息循环管理全部浏览器窗口，普通窗口彼此不设 owner。关闭第一个窗口后，其他窗口继续工作，广告拦截继续生效。
- **标签异步竞态**：初始化任务和挂起任务检查所属视图；旧任务不能操作后来重建的视图。激活标签会撤销尚未完成的挂起请求。
- **驻留预算错误**：尚未加载的后台标签不占名额；创建新视图前先回收超限视图。后台保持挂起，切回时再恢复。
- **切换卡顿来源**：自动休眠不再逐个执行强制 GC 和工作集清空，手动回收保留主动工作集整理。
- **内存统计混入其他应用**：按使用中的 WebView2 环境获取进程 ID，对多个窗口的共享进程去重。
- **首页与地址识别**：首页加载后的 `about:blank` 不再覆盖内部标记；首页搜索转为正常导航。地址识别只检查主机，保留内部地址和带空格的 file URL；普通域名默认使用 HTTPS，IP 和 localhost 使用 HTTP。
- **图片开关失效**：在网络请求阶段拦截图片，而不是只用 CSS 隐藏已经下载的图片。
- **密码保存与填充**：补齐首次登录的提交监听，保存时使用提交页面的来源。凭据按完整 origin 隔离，账号选择需要当前文档令牌，脚本中的选择监听只接受真实鼠标事件；调试日志不写消息原文。
- **管理页通信来源**：只接受指定内部页面的消息，派发前再次确认当前来源，并限制各页面可调用的操作。向页面推送数据前也检查来源。
- **无痕记录与清理**：使用内核 InPrivate 控制器，不写入普通历史和下载记录；关闭时等待私有环境进程退出，再清理临时目录，包括启动途中关闭的情况。
- **字体异常与资源增长**：四档界面倍率共用最多 28 个缓存字体，不释放仍被控件使用的对象；倍率刷新先生成新字体，再分发到控件。系统主题通知转回 UI 线程。
- **操作与设置**：修复 Ctrl+J / Ctrl+H / Ctrl+Shift+O、反向切换标签和下载文件定位。内部页面在禁用网页 JavaScript 后仍可使用；移除无效的桌面网站选项，Windows 内核默认请求桌面页面。
- **构建与诊断**：在依赖解析前移除未使用的 WebView2 WPF 引用，解决 WindowsBase 冲突；清理其余编译警告。内存自检使用实际配置和导航完成结果，默认隔离日常数据。
- **安装与卸载**：发布脚本默认读取项目版本号，支持指定免安装版 NSIS，清理旧发布文件以避免混入 DLL。安装包附带经微软 Authenticode 验证的 WebView2 引导程序，替换不支持 HTTPS 的 NSISdl 下载流程。补齐安装文件版本信息，静默卸载默认保留个人数据；卸载不再结束其他应用的全部 WebView2 进程。

## 验证

```powershell
dotnet build src/FeatherBrowser.csproj -c Release
dotnet run --project tests/FeatherBrowser.Tests.csproj -c Release
```

回归程序使用真实 WebView2、仅监听回环地址的本地测试服务以及独立临时数据目录。覆盖地址识别、凭据隔离、字体刷新、首页搜索、驻留上限、快速切换、异步挂起、图片请求、管理页通信、JavaScript 设置、首次密码提交、伪造账号选择、内核失败恢复、无痕记录、多窗口退出、会话保存、临时目录清理与进程归属统计。原始结果见 [regression-report.txt](regression-report.txt)。

本轮结果：Release 编译 0 警告、0 错误；18 项回归检查全部通过。

1.4.1 安装包使用 NSIS 3.13 打包 `win-x64` 自包含目录，包含 .NET 8 运行时，未启用 IL 裁剪。
另将回归程序发布为自包含版本，核对其 `FeatherBrowser.dll` 的 SHA-256 与安装负载一致后运行，18 项检查全部通过。
安装程序编译成功，文件属性的产品版本和文件版本均为 1.4.1。未在当前工作电脑执行系统级安装与卸载，缺失 WebView2 的全新系统安装路径尚未实际运行。

测试验证功能和驻留上限，没有重新测量大型网站组合的长期内存曲线。旧版自检报告的绝对内存值含有其他应用的 WebView2，不能与本轮统计直接比较。网站兼容性、完整公共后缀规则和多显示器 DPI 布局仍需进一步覆盖。

内核失败测试模拟转发事件来验证重建路径，没有结束本机其他应用的浏览器进程。

## 行为变化

普通窗口保存最后关闭窗口的会话；本轮没有增加多个窗口一起恢复的会话格式。密码仅在保存的协议、主机和端口下提供，已有凭据不会自动跨子域或从 HTTPS 下放到 HTTP。关闭图片加载需刷新页面，已下载资源和内联图片不属于网络图片拦截范围。
